Importante

Windows può dire «virus»: è un falso positivo

L’installer della bozza di Tata non è ancora firmato (il certificato costa; arriva dopo). Windows Defender / SmartScreen può mostrare «minaccia rilevata», Trojan, Wacatac, o «Windows ha protetto il PC». Non è malware: è un falso positivo sugli EXE non firmati di una bozza. Tata è sicuro.

  1. SmartScreen («Windows ha protetto il PC»): clicca Ulteriori informazioni → poi Esegui comunque.
  2. Quarantena di Defender: apri Sicurezza di Windows → Cronologia protezione → seleziona il file di Tata → Consenti sul dispositivo (oppure Ripristina).

Non spegnere Windows Defender per sempre. Consenti solo questo installer di Tata.

Perché non è firmato? È una bozza: la firma Authenticode arriva quando compriamo il certificato.

!

Importante · Mac

Gatekeeper può bloccare l’app: bozza non firmata

La build Mac non è ancora notarizzata né firmata con Developer ID. macOS può dire che l’app è «danneggiata e non può essere aperta» o «da uno sviluppatore non identificato». È Gatekeeper su una bozza non firmata: il download non è corrotto.

  1. Trascina Tata in Applicazioni, poi nel Terminale esegui: xattr -cr "/Applications/Tata.app" e riapri l’app.
  2. Oppure nel Finder: tasto destro sull’app → Apri → conferma Apri.
  3. Oppure: Impostazioni di Sistema → Privacy e sicurezza → Apri comunque.

Il DMG per Mac, per ora, è solo Apple Silicon (arm64). I Mac Intel arrivano dopo, con una build a parte.

Dopo il download: Windows → Ulteriori informazioni → Esegui comunque; Mac → tasto destro → Apri (vedi i riquadri ambra qui sopra).

Si apre in tre passi

Niente account e niente chiave. Il quaderno vive su quel computer.

  1. 1
    Installa

    Scarica Windows o Mac da questa pagina. Se Windows avvisa, segui il riquadro ambra: Ulteriori informazioni → Esegui comunque. Sul Mac: tasto destro sull’app → Apri.

  2. 2
    Apri

    Si apre la finestra Tata. La prima volta trovi i dati di esempio: famiglie Bianchi, Ferri e Greco, a Lugano. Chiudi la finestra per spegnere anche il programma.

  3. 3
    Metti i tuoi dati

    Nome, famiglie, tariffe orarie e a giornata, poi l’IBAN per il QR. Dalle Impostazioni puoi svuotare gli esempi o scaricare una copia. Per consegnare una fattura: aprila e usa Stampa o salva PDF.
